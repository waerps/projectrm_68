# พาชมสถาบัน

- `../VirtualTour.jsx` เป็นหน้า React ที่ผู้ใช้เปิดผ่าน `/virtual-tour` และมีปุ่มเลือกชั้นในแผงซ้าย ส่วน Navbar ใช้ตัวเดียวกับหน้าอื่นของเว็บ
- `../VirtualTour.css` กำหนดหน้าตาของทัวร์ทั้งคอมพิวเตอร์และมือถือ
- `welcomeContent.js` เก็บชื่อและคำอธิบายจุดต่าง ๆ ในชั้น 1
- `roomData.js` เก็บข้อมูลห้องจากเดโมเดิม ข้อมูลนี้เป็นภาพรวมเพื่อแนะนำห้อง ไม่ใช่สถานะห้องแบบสด
- `welcomeScene.js` และ `classroomScene.js` สร้างโมเดล 3D สำหรับหมุน ซูม และเลือกพื้นที่หรือห้อง
- `public/tour/` มีเพียงภาพพรีวิว ภาพสถานที่จริง และไฟล์ Three.js ที่โมเดลเดิมใช้อยู่

ลิงก์จาก Home ใช้ `/virtual-tour?floor=1`, `?floor=2` และ `?floor=3` หากเข้าไปดูห้องหนึ่ง ห้องนั้นจะเก็บหมายเลขไว้ใน `?room=...` เพื่อเปิดซ้ำได้

ชั้น 1 มีพื้นที่ต้อนรับ ห้อง 1 (8 ที่นั่ง) และห้อง 0 (ยังไม่ใช้งาน) โดยเลือกสองห้องนี้ได้จากเมนูด้านซ้ายของหน้าพื้นที่ต้อนรับ
